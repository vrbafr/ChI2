# Text file counter

This script reads `test.txt` from the same directory and prints the total
number of characters and the number of uppercase letters.

## Requirements

- Git
- Python 3

## Clone the repository

In a terminal, clone the repository and change to the directory containing the
script:

```powershell
git clone https://github.com/vrbafr/ChI2.git
cd ChI2\A02
```

## Run the script

Run the script with Python 3 from the `A02` directory:

```powershell
python texter.py
```

On systems where Python 3 is invoked as `python3`, use:

```powershell
python3 texter.py
```

The script uses the `test.txt` file in this directory. Its output reports the
total character count and uppercase-letter count.
